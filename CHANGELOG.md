# Changelog

## v0.14.0
- Reworked Settings as a launcher-style workspace with a sidebar, constrained resizing, and lightweight page transitions.
- Added an Open Wheel control and direct launching for saved application/website tiles.
- Shows the native Windows icon for custom executable tiles where available.
- Added preferences for launching at Windows sign-in, keeping Cinder in the tray when the launcher closes, and reducing animations.
- Added single-instance handoff so a launcher shortcut can bring the existing Cinder window forward instead of launching a second dial listener.
- Stores installed configuration under the user's Local AppData directory; existing source-mode configuration remains beside the source files.
- Added an Inno Setup script for a standard installer with an install-directory page, Start Menu shortcut, optional desktop shortcut, and post-install launch.


## v0.13.0
- Faster default dictation model and redesigned settings.
